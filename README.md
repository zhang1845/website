# 拾页 · 个人网站

纯 HTML、CSS、JavaScript 的个人博客，无需安装依赖。所有文件直接放在当前 website 文件夹下。

## 查看网站

双击 `index.html` 即可查看，也可以在 VS Code 中使用 Live Server 打开。

## 修改内容

- `index.html`：站名、首页介绍、关于我等文字。
- `app.js`：`profile.email` 填写真实邮箱；`articles` 数组编辑文章标题、分类、日期、摘要和正文。所有初始文章均为示例。
- `style.css`：页面样式、配色和手机适配。

支持文章分类、关键词搜索、文章阅读弹窗、深浅主题切换及主题记忆。文章链接使用 URL hash，可直接分享。此版本不包含管理后台，更新文章请编辑源文件。

这是本地网站，未为此次创建执行线上部署。
