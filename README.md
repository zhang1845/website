# Zhang · 个人网站

纯 HTML、CSS、JavaScript 的个人博客，无需安装依赖。所有文件直接放在当前 website 文件夹下。

## 查看网站

双击 `index.html` 即可查看，也可以在 VS Code 中使用 Live Server 打开。

## 修改内容

- `index.html`：站名、首页介绍、关于我等文字。
- `app.js`：`profile.email` 填写真实邮箱；`articles` 数组编辑文章标题、分类、日期、摘要和正文。所有初始文章均为示例。
- `style.css`：页面样式、配色和手机适配。

支持文章分类、关键词搜索、文章阅读弹窗、深浅主题切换及主题记忆。文章链接使用 URL hash，可直接分享。此版本不包含管理后台，更新文章请编辑源文件。

这是本地网站，未为此次创建执行线上部署。

## 设计与内容

新版参考用户提供视频中已读取到的首屏布局，采用暖米色、超大衬线标题、左右分栏和简洁按钮。使用原创 SVG 抽象雕塑，未复制参考人物图像；支持减少动态效果的系统偏好。

新增真实 website 项目的展示与 GitHub 入口。显示名暂用 GitHub 用户名中的 Zhang，可在 index.html 中修改。没有虚构工作履历、项目成果或联系方式。

## 首页动画头像

首页使用 `assets/zhang-avatar-3d.png` 作为透明背景的 3D 卡通形象。头像根据本人照片创作，桌面端支持鼠标跟随、轻微倾斜、光源移动和呼吸漂浮；触屏设备保留轻微自动动画。系统启用“减少动态效果”时，交互和循环动画会自动停止。
